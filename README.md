# Orderbook Volt Plugin

A high-performance orderbook visualization plugin for the Orderly Network ecosystem.
Built with React + TypeScript for real-time trading interfaces requiring custom
theme integration and lightweight rendering.

## Features

- Custom voltage theme with dark mode support
- Lightweight — zero runtime dependencies beyond peer requirements
- TypeScript-first with full type exports
- Compatible with Orderly SDK 3.x plugin architecture

## Installation

npm install orderbook-volt-plugin

See configSchema.json for the full configuration schema.
